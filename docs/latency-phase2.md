# 응답시간 개선 2차

공개 범위를 확인한 뒤 자료와 답변 설정을 병렬 조회한다. 설정은 요청 안에서만 재사용하여 변경된 설정과 API 키가 다음 요청에 반영된다.

모델 입력은 사업 정보, 전체 자료, 검증된 연락처, 날짜, 대화 순으로 배치한다. 날짜 변경이 자료 앞부분의 공통 접두사를 깨지 않도록 한다. 이는 제공자 암묵적 캐시 활용을 위한 배치이며 캐시 적중이나 지연 단축을 보장하지 않는다. 전체 자료, 대화, 추론 설정과 답변 검증을 유지한다.

기존 배포와 비교하는 테스트는 입력 JSON의 필드 순서만 제외하고 전체 모델 입력, 최종 답변, 저장 내역을 비교한다. 표시 애니메이션은 초당 90자다.

아직 측정된 운영 개선율은 없다. 기존 Chat timing의 model, knowledge, configuration, validation, usage, consultation과 totalMs로 평가한다. 병렬 구간과 상위 구간은 더하지 않는다. FAQ 제외 요청의 평균 및 p95, 캐시 입력 토큰, 오류율을 비교해야 한다.

자료 검색 축소 및 복합 질문의 병렬 모델 검토는 이번 변경에 포함하지 않는다. 품질검사 9회와 정상 사례에 대한 실제 모델 평가에서 조건 누락과 오답이 늘지 않는지 검증한 뒤 도입한다. 모의 모델 테스트는 실제 모델 정확도 향상의 증거가 아니다.
